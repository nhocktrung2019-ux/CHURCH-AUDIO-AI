# v0.23.0-beta.1 — Channel calibration foundation

## Goal
Introduce a fail-closed data model for calibrating the electrical loopback path used by synchronous Reference/Measurement Transfer Function. A profile is tied to the exact interface identity, input channel, output identity and sample rate.

## Implemented in this increment
- Versioned calibration profile with strict finite/range/order checks.
- Require at least 3 measured points covering 50 Hz–10 kHz; reject extrapolation for interpolation.
- Log-frequency interpolation for measured magnitude and phase response.
- Exact compatibility checks for interface, channel, output and sample rate.
- Correct measured H1 magnitude/phase by subtracting the captured loopback path; correct relative delay by subtracting calibrated loopback delay.
- Unit tests cover malformed/duplicate points, bandwidth, compatibility, interpolation bounds and correction arithmetic.

## Safety and validity constraints
- This module does not discover or identify hardware by itself. The capture layer must provide a stable device key and the actual channel/output selection.
- A profile must be generated from a known electrical loopback with safe line-level attenuation and repeated measurements. It must not be fabricated from manufacturer specifications or guessed values.
- Do not reuse profiles after changing interface, input channel, output, sample rate, gain topology or routing.
- This only compensates the measured electrical path. It does not calibrate microphone response, loudspeaker response, room acoustics, analog gain linearity, independent clock drift or physical ADC/DAC behaviour.
- Keep synchronous Auto EQ disabled until capture integration, calibration workflow, Android hardware testing and comparison against a calibrated analyser all pass.
