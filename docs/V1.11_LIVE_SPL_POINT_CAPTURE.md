# v1.11 — Live SPL point capture

## Delivered in this increment
- Adds a live capture panel to the existing 3D design workflow.
- Reads the active A/C/Z weighted level values from the existing microphone analyzer.
- Uses the currently active one-point microphone calibration offset.
- Saves a timestamped measured-point record to the same persistent store used by the 3D measured-point overlay and SPL surface.
- Requires an active microphone, non-zero calibration offset, non-clipped input peak and in-room X/Y/Z coordinates.
- Preserves existing measurement records and labels the input source.

## Important limitations
- Coordinates are entered by the operator; no automatic indoor positioning is claimed.
- Existing software weighting and one-point offset are not certified IEC 61672 measurements.
- A single offset does not replace a traceable acoustic calibrator check or microphone frequency correction.
- Physical validation on the target Android phone and measurement microphone is still required.

## Validation required
- Confirm useAudioAnalyzer weighting outputs and calibration offset with a known reference source.
- Verify local persistence and 3D overlay after app restart.
- Verify Android microphone permission, foreground behavior and touch layout.
- Confirm saved points remain distinct from simulated and interpolated SPL surfaces.
